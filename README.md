# Rahul Vadhs - Professional Photographer

A stunning Next.js portfolio website for Rahul Vadhs, professional photographer specializing in weddings, portraits, events, and creative photography. Features advanced SEO optimization, interactive galleries, and modern web technologies.

## 🚀 Features

- **Complete SEO Optimization**: Meta tags, structured data, sitemap, robots.txt
- **Interactive Photo Gallery**: Cloudinary-powered gallery with modal views
- **Performance Optimized**: Image optimization, lazy loading, compression
- **3D Elements**: Interactive 3D models and animations using Three.js
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **PWA Ready**: Service worker and manifest for offline functionality
- **Contact Integration**: Professional enquiry forms

## 🛠️ Tech Stack

- **Framework**: Next.js 16 with App Router
- **Styling**: Tailwind CSS with custom animations
- **3D Graphics**: Three.js with React Three Fiber
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Forms**: React Hook Form with Zod validation
- **Analytics**: Vercel Analytics

## 📈 SEO Features

### Meta Tags

- XML sitemap generation

- Semantic HTML structure
- Accessible navigation and forms
